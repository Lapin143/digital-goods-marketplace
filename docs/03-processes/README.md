# 03. Процессы и статусные модели

| Артефакт | Формат | Именование |
| --- | --- | --- |
| Бизнес-процессы | BPMN (редактор bpmn.io) | `BPMN-NN-name.bpmn` и картинка `BPMN-NN-name.png` рядом |
| Статусные модели | Markdown + диаграмма Mermaid + матрица переходов | `SM-NN-name.md` |

Матрица переходов статусной модели: «из → в → условие → кто или что инициирует». Недопустимые переходы перечисляются отдельно.
