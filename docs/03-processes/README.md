# 03. Процессы и статусные модели

| Артефакт | Формат | Именование |
| --- | --- | --- |
| Бизнес-процессы | BPMN (редактор bpmn.io) | Три файла: `BPMN-NN-name.bpmn` (диаграмма), `BPMN-NN-name.svg` (картинка для просмотра на GitHub), `BPMN-NN-name.md` (описание: участники, триггер, требования, основной путь, исключения, решения) |
| Статусные модели | Markdown + диаграмма Mermaid + матрица переходов | `SM-NN-name.md` |

Матрица переходов статусной модели: «из → в → условие → кто или что инициирует». Недопустимые переходы перечисляются отдельно.

## Бизнес-процессы

Релиз R1 проработан полностью, процессы R2 нарисованы укрупнённо. Во всех процессах раздел «Решения и открытые вопросы» заканчивается строкой «Открытых вопросов по процессу нет».

| Процесс | Релиз | Описание |
| --- | --- | --- |
| BPMN-01 | R1 | [Покупка цифрового товара](BPMN-01-purchase.md): резерв, оплата, выдача, поздняя оплата, автовозврат |
| BPMN-02 | R1 | [Подключение продавца](BPMN-02-seller-onboarding.md): анкета, модерация, повторная заявка после отказа |
| BPMN-03 | R1 | [Модерация товара](BPMN-03-product-moderation.md): создание товара, пул ключей, решение модератора |
| BPMN-04 | R1 | [Обращение в поддержку](BPMN-04-support-request.md): повторная отправка, смена e-mail, вход по SMS |
| BPMN-05 | R2 | [Спор](BPMN-05-dispute.md): открытие, ответ продавца, решение, возврат или замена ключа |
| BPMN-06 | R2 | [Вывод средств](BPMN-06-withdrawal.md): начисление, удержание, заявка, ручная выплата |
| BPMN-07 | R2 | [Смена номера телефона](BPMN-07-phone-change.md): коды на e-mail и на новый номер |

## Статусные модели

В каждой модели есть диаграмма Mermaid, матрица переходов (номера T1, T2 и так далее), недопустимые переходы с причинами и решения, принятые при моделировании. На переход можно сослаться в виде «SM-01/T4».

| Модель | Сущность | Статусы | Релиз |
| --- | --- | --- | --- |
| [SM-01](SM-01-order.md) | Заказ | создан, ожидает оплаты, оплачен, выдан, отменён, возвращён | R1 |
| [SM-02](SM-02-payment.md) | Платёж | создан, подтверждён, отклонён, возвращён | R1 |
| [SM-03](SM-03-key.md) | Ключ | свободен, зарезервирован, выдан, аннулирован | R1 |
| [SM-04](SM-04-product.md) | Товар | черновик, на модерации, опубликован, отклонён, заблокирован, архив | R1 |
| [SM-05](SM-05-seller-profile.md) | Профиль продавца | черновик, на проверке, на доработке, одобрен, отклонён, заблокирован | R1 |
| [SM-06](SM-06-delivery.md) | Выдача | в очереди, отправлено, доставлено, ошибка | R1 |
| [SM-07](SM-07-support-ticket.md) | Обращение в поддержку | создано, в работе, решено | R1 |
| [SM-08](SM-08-reservation.md) | Резерв | активен, использован, снят | R1 |
| [SM-09](SM-09-dispute.md) | Спор | открыт, ожидает решения, решён | R2 |
| [SM-10](SM-10-withdrawal.md) | Заявка на вывод | создана, на проверке, выплачена, отклонена | R2 |
| [SM-11](SM-11-balance-operation.md) | Операция по балансу | заморожена (удержание, спор, резерв под вывод), доступна, выплачена, сторнирована | R2 |

Сквозная таблица согласованности статусов заказа, платежа, ключа, резерва и выдачи находится в [SM-01](SM-01-order.md).
