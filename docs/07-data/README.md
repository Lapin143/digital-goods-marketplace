# 07. Физические модели данных

Схема базы данных каждого сервиса: таблицы, индексы, уникальные ограничения, таблицы outbox и обработанных событий.

| Файл | Содержимое |
| --- | --- |
| `<service>-schema.md` | Описание таблиц сервиса, обоснование индексов, способ обеспечения каждого инварианта INV-NN |
| `ddl/<service>.sql` | SQL создания схемы для PostgreSQL 16, проверен прогоном с нуля |

Шаг 12 Ф2. Логическая модель, из которой выведены таблицы, лежит в [04-domain](../04-domain/README.md).
