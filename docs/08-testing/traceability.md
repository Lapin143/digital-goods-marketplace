# Матрица трассировки

Цепочка: BG → FT/NFT → US → BPMN / UC / SM → API или событие → TC → код.

Матрица растёт по фазам: v1 после Ф1 (цель, требование, story, процесс), v2 после Ф2 (API и события), v3 после Ф4 (тест-кейсы и код). Веха закрывается, когда в матрице нет пустых клеток для объёма этой вехи.
