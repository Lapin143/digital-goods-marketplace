# 06. API и события

| Папка | Содержимое | Состояние |
| --- | --- | --- |
| `openapi/` | Контракты REST API в формате OpenAPI (YAML), по одному файлу на сервис. Релиз R1 | Шаг 11 Ф2 |
| [asyncapi/](asyncapi/asyncapi.yaml) | Контракт событий Kafka в формате AsyncAPI 3.0: 11 тем, 55 событий, схемы данных, издатели, потребители, ключи идемпотентности, обработка ошибок | Готово, шаг 10 Ф2 |
| [events/](events/README.md) | Каталог событий (таблицы генерируются из контракта) и примеры сообщений: по файлу на событие в `events/examples/` | Готово, шаг 10 Ф2 |

Контракты пишутся до кода (contract-first) и версионируются. Общие правила (формат идентификаторов, деньги, время, ошибки, пагинация, заголовки, конверт события, повторы) записаны в [conventions.md](../05-architecture/conventions.md).

**Проверка контракта событий.** Скрипт `check_asyncapi.py` разбирает контракт: структура и ссылки, схемы данных, примеры по схемам, по одному издателю на событие, владение агрегатом, ключ идемпотентности у каждого потребителя, сверка с реестром событий ([c4-components.md](../05-architecture/c4-components.md), раздел 5.3), со списками «Публикует» в [bounded-contexts.md](../04-domain/bounded-contexts.md) и с таблицами «Читает» в документах компонентов. Скрипт переносится в `tools/docs-checks` на шаге 14.
