# 06. API и события

| Папка | Содержимое |
| --- | --- |
| `openapi/` | Контракты REST API в формате OpenAPI (YAML), по одному файлу на сервис |
| `asyncapi/` | Контракты событий Kafka в формате AsyncAPI (YAML) |
| `events/` | Описания и примеры схем событий |

Контракты пишутся до кода (contract-first) и версионируются.
