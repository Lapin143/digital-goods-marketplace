# 06. API и события

| Папка | Содержимое |
| --- | --- |
| `openapi/` | Контракты REST API в формате OpenAPI (YAML), по одному файлу на сервис. Релиз R1, шаг 11 Ф2 |
| `asyncapi/` | Контракт событий Kafka в формате AsyncAPI 3.0 (YAML). Шаг 10 Ф2 |
| `events/` | Каталог событий и примеры сообщений. Шаг 10 Ф2 |

Контракты пишутся до кода (contract-first) и версионируются. Общие правила (формат ID, деньги, время, ошибки, конверт события) записаны в `docs/05-architecture/conventions.md`.
