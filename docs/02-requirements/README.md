## User stories

Один файл на эпик. В каждом файле вверху таблица историй, ниже сами истории: поля (ID, релиз, требования, процесс), история «Как..., я хочу..., чтобы...», критерии приёмки, примечания. Правила, по которым написаны истории:

- Все идентификаторы FT и NFT взяты из требований v1.5, новых нет. Каждое требование релиза R1 покрыто хотя бы одной историей релиза R1.
- Роли берутся из раздела 3 требований, для автоматических действий используется роль «Система». Заявитель на статус продавца это покупатель, подавший заявку.
- Числа в критериях взяты из требований: резерв 15 минут, платёжная сессия 12 минут, окна 72 часа, срок модерации 3 суток, одноразовый код 5 минут и 5 попыток.
- Эксплуатационные качества без пользовательского сценария (восстановление, масштабирование, язык интерфейса) оформлены историями US-8.10, US-8.11 и US-8.12, чтобы у каждого NFT релиза R1 был проверяемый критерий.
- Решения, принятые при написании историй, перечислены в конце каждого файла в разделе «Решения и открытые вопросы».

Дальше от историй идёт трассировка: процесс, use case, статусная модель, API, тест-кейс. Матрица трассировки находится в `docs/08-testing/traceability.md`.
