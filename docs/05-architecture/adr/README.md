# Записи архитектурных решений (ADR)

Каждое существенное решение оформляется отдельным файлом по шаблону [_template.md](_template.md). Имя файла: `ADR-NNN-short-name.md`, например `ADR-005-transactional-outbox.md`.

Принятое заранее решение ADR-001 (покупка без корзины) описано в приложении A [требований](../../02-requirements/requirements_v1.5.md). Остальные ADR добавляются по плану: список тем и рассмотренных альтернатив в разделе 8 [плана проекта](../../00-project-plan.md).

В каждой записи есть контекст, не меньше двух рассмотренных вариантов с плюсами и минусами, решение, последствия и условие пересмотра. Полноту проверяет скрипт проверки документов.
