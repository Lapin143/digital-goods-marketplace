# infra/redis

Redis 8 (образ `redis:8.10.2-alpine`): кэш каталога, счётчики ограничения частоты, одноразовые коды, таймеры резервов. Данные временные, потеря допустима ([ADR-012](../../docs/05-architecture/adr/ADR-012-reservation-redis-timer.md)).

| Файл | Назначение |
| --- | --- |
| `redis.conf` | Только TLS (обычный порт закрыт), `maxmemory` 64 МБ, `noeviction`, без сохранения на диск |
| `entrypoint.sh` | Собирает файл пользователей ACL из секретов (в файле хранятся SHA-256 паролей) и запускает `redis-server` |

## Пользователи и права

Один пользователь на сервис, ключи разделены префиксами. Пользователь `default` выключен.

| Пользователь | Секрет | Ключи | Что хранит |
| --- | --- | --- | --- |
| `gateway` | `redis_gateway` | `request_rate_limiter.*`, `apikey:*` | Счётчики ограничения частоты (имена задаёт Spring Cloud Gateway), R2: кэш проверки API-ключа |
| `catalog` | `redis_catalog` | `catalog:*` | Кэш карточек и поиска |
| `inventory` | `redis_inventory` | `reservation:*` | Таймеры резервов (`reservation:expiry`) |
| `platform` | `redis_platform` | `platform:*` | Одноразовые коды, счётчики попыток и запросов |
| `admin` | `redis_admin` | Все | Проверка готовности и администрирование, только внутри контейнера |

Командам сервисов разрешены чтение, запись и скрипты Lua. Шлюзу дополнительно разрешена `TIME`: скрипт ограничителя частоты Spring Cloud Gateway читает время сервера (шаг 13 Ф3; без этого права скрипт получал `NOPERM` внутри Lua на каждый запрос, шлюз пропускал запросы без лимита, и только проверка стенда это показала). Опасные команды (`FLUSHALL`, `KEYS`, `CONFIG`, `DEBUG` и прочие категории `@dangerous`) запрещены. Префиксы ключей это соглашение проекта: сервис, который запишет ключ вне своего префикса, получит `NOPERM`, и это найдёт тест.

## Замечания

- Предупреждение `Memory overcommit must be enabled` при старте безвредно: сохранение на диск выключено, `fork` не выполняется.
- Подключение с хоста для отладки: `make up SET=dev-min DEBUG=1`, затем `redis-cli --tls --cacert secrets/tls_ca.crt -p 16379 --user admin` (пароль в `secrets/redis_admin`, передавайте через `REDISCLI_AUTH`).
