# frontend

Веб-интерфейс: покупатель, продавец, модератор, оператор поддержки.

| Папка | Состояние | Содержимое |
|---|---|---|
| `web-app/` | Заглушка Ф3 (шаг 14) | `nginx.conf` и статические файлы `public/`: страница со ссылкой на витрину и проверкой из браузера, что витрина отвечает через шлюз. Образ собирает `docker/Dockerfile.web`, контейнер `web-app` входит в профиль `gateway`, страницу получает только шлюз по mTLS |

Настоящий интерфейс на React появится в Ф4: сборка Vite (`npm run build`) положит файлы в `web-app/public`, конфигурация nginx получит возврат `index.html` для адресов клиентского маршрутизатора.
Описание контейнера: [c4-deployment.md](../docs/05-architecture/c4-deployment.md), решение 21.
