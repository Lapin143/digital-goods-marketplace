Маркетплейс цифровых товаров

Заглушка веб-интерфейса. Настоящий интерфейс на React появится в четвёртой фазе проекта. Сейчас эта страница показывает, что стенд работает: её отдал контейнер web-app через единую точку входа, шлюз, по HTTPS.

Состояние

  • Страница получена через шлюз по HTTPS
  • Витрина отвечает через шлюз: проверяется…

Интерфейс API

  • Витрина: список опубликованных товаров (JSON)
  • Витрина: первые три товара

Остальные операции требуют входа (Keycloak) и токена доступа. Описание всех операций лежит в репозитории проекта, папка docs/06-api/openapi.
