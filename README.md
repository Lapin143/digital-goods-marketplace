# Маркетплейс цифровых товаров

Учебный портфолио-проект: платформа, на которой продавцы размещают цифровые товары (ключи игр, лицензии ПО, подарочные карты, подписки), а покупатели получают оплаченный товар на e-mail в течение 30 минут. Платформа зарабатывает на комиссии с каждого заказа.

Система строится на микросервисной архитектуре и сопровождается полным комплектом документации: от бизнес-целей и BPMN до OpenAPI, AsyncAPI и записей архитектурных решений (ADR).

## Что здесь интересного

- **Гарантированная доставка.** Повторы с нарастающей задержкой, отслеживание статуса письма, очередь недоставленных сообщений (DLQ), автоматическая передача в поддержку.
- **Защита от двойной выдачи ключа.** Блокировка строки `FOR UPDATE SKIP LOCKED`, уникальные ограничения, идемпотентная обработка событий.
- **Saga «резерв → оплата → выдача»** с компенсациями. Поздняя оплата: перерезервирование или автовозврат через платёжный шлюз.
- **Transactional Outbox** для надёжной публикации событий в Kafka.
- **Безопасность и данные.** Шифрование ключей (AES-256), HMAC для проверки дублей, журнал аудита без персональных данных (152-ФЗ).
- **Бизнес-функции.** Модерация продавцов и товаров, комиссия, баланс продавца, споры, API продавца.

## Стек

Java (Spring Boot), PostgreSQL + Flyway, Kafka, Redis, Keycloak (OAuth2, JWT), API Gateway, MinIO, React, Docker Compose, GitHub Actions. По плану также k3s + Helm, Prometheus, Grafana, Loki, OpenTelemetry, OpenSearch, gRPC.

## Статус

Фазы Ф1 «Аналитика» и Ф2 «Архитектура и контракты» завершены (вехи M1 и M2). Есть аналитическая база и архитектура релиза R1: C4, 16 ADR, 68 операций OpenAPI, 55 событий AsyncAPI, схемы шести баз на PostgreSQL 16, стратегия тестирования и матрица трассировки. Следующая фаза Ф3: каркас (Compose, Kafka, Keycloak, шлюз, CI). Код сервисов появится в Ф4.
