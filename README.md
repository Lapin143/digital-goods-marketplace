# Маркетплейс цифровых товаров

Учебный портфолио-проект: платформа, на которой продавцы размещают цифровые товары (ключи игр, лицензии ПО, подарочные карты, подписки), а покупатели получают оплаченный товар на e-mail в течение 30 минут. Платформа зарабатывает на комиссии с каждого заказа.

Система строится на микросервисной архитектуре и сопровождается полным комплектом документации: от бизнес-целей и BPMN до OpenAPI, AsyncAPI и записей архитектурных решений (ADR).

## Что здесь интересного

- **Гарантированная доставка.** Повторы с нарастающей задержкой, отслеживание статуса письма, очередь недоставленных сообщений (DLQ), автоматическая передача в поддержку.
- **Защита от двойной выдачи ключа.** Блокировка строки `FOR UPDATE SKIP LOCKED`, уникальные ограничения, идемпотентная обработка событий.
- **Saga «резерв → оплата → выдача»** с компенсациями. Поздняя оплата: перерезервирование или автовозврат через платёжный шлюз.
- **Transactional Outbox** для надёжной публикации событий в Kafka.
- **Безопасность и данные.** Шифрование ключей (AES-256), HMAC для проверки дублей, журнал аудита без персональных данных (152-ФЗ).
- **Бизнес-функции.** Модерация продавцов и товаров, комиссия, баланс продавца, споры, API продавца.

## Стек

Java (Spring Boot), PostgreSQL + Flyway, Kafka, Redis, Keycloak (OAuth2, JWT), API Gateway, объектное хранилище S3 (RustFS), React, Docker Compose, GitHub Actions. По плану также k3s + Helm, Prometheus, Grafana, Loki, OpenTelemetry, OpenSearch, gRPC.

## Статус

Фазы Ф1 «Аналитика», Ф2 «Архитектура и контракты» и Ф3 «Каркас» завершены (вехи M1, M2 и M3). Есть аналитическая база и архитектура релиза R1 (C4, 18 ADR, 68 операций OpenAPI, 55 событий AsyncAPI, схемы шести баз на PostgreSQL 16, стратегия тестирования, матрица трассировки) и работающий каркас: 22 контейнера в Docker Compose (16 в наборе `full`, 6 стека наблюдения) с TLS между всеми компонентами, Keycloak с realm как кодом, шлюз с проверкой токенов и ограничением частоты, шесть сервисов на Java 25 и Spring Boot 4.1 с тремя операциями «ходячего скелета», стек наблюдения, замеры памяти и CI из 16 заданий, который проверяет всё это на каждом коммите. Следующая фаза Ф4: срезы бизнес-логики (витрина и покупатель, платёж и выдача, поддержка и модерация).

## Быстрый запуск

Нужны Docker с Compose, GNU Make, JDK 25 (для сборки), Python 3.12 и `openssl`. На Windows 11 установка через WSL2 описана в [руководстве разработчика](docs/09-operations/developer-guide.md). Клонируйте репозиторий в домашний каталог Linux (не в `/mnt/c`), затем:

```bash
make up SET=dev-purchase DEBUG=1   # PostgreSQL, Kafka, Redis, заглушки, Keycloak, шлюз и пять сервисов покупки
make keycloak-users                # тестовые пользователи (пароли в secrets/test_users.json)
make demo                          # токен от Keycloak: запрос без токена получает 401, с токеном 200
make down                          # остановить, данные сохраняются
```

`make up` сам создаёт частный центр сертификации и секреты (в Git они не попадают). Наборы под ноутбук с 3 ГБ для WSL (`dev-min`, `dev-platform`, `dev-auth`, `dev-purchase`), полный набор `full-obs` для сервера и все проверки перечислены в [руководстве разработчика](docs/09-operations/developer-guide.md), порядок действий при сбоях в [runbook](docs/09-operations/runbook.md).
